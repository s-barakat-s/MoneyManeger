تمام. بعد كل الـscreens اللي راجعناها، عندنا صورة كاملة تقريبًا، وأقدر أحط **Master UI Redesign Plan** للتطبيق كله.

الاتجاه اللي أنصح به: **Professional Financial SaaS** — هادي، دقيق، نظيف، سريع في القراءة، ومش مهرجان ألوان. هنستفيد من فلسفة Material في الـadaptive/accessibility foundations، ومن Apple في وضوح الـhierarchy والـmodality، ومن Fluent في desktop density والـlayout والـmotion. ([Material Design][1])
مش هننسخ أي Design System حرفيًا؛ هنطلع **Money Manager Design System** خاص بينا.

# الرؤية النهائية

الشكل المستهدف:

**80–90% Neutral UI**
أبيض/رمادي في Light، وفحمي/أسود هادئ في Dark.

**Purple = Brand & Primary Action فقط.**

الألوان الأخرى لها معنى فقط:

```text
Purple   → Brand / selected / primary action
Green    → Income / positive / success
Red      → Expense / debt / destructive
Blue     → Receivable / informational
Amber    → Assets / warning
Neutral  → كل باقي الـUI
```

يعني ممنوع كل Card يبقى له لون وخلفية وGlow مختلفين.

```text

```

وده هيحل تقريبًا نص مشاكل Desktop اللي شفناها.

# UI-5 — Radius / Border / Shadow

نقلل عدد الـradii.

مثلًا:

```text
Small controls      8
Inputs/buttons      10–12
Cards               14–16
Sheets/dialogs      20–24
```

مفيش 7 أشكال Rounded مختلفة.

Shadow تستخدم فقط لما hierarchy محتاج elevation؛ Fluent أيضًا يعامل elevation كوسيلة لتوضيح مستوى العنصر وأهميته، مش كزينة. ([Fluent 2 Design System][3])

Light mode نعتمد أكتر على border + subtle shadow.

Dark mode نعتمد أكتر على surface contrast + border، وليس glow.

# UI-6 — Buttons


# الـQuick Add — Signature Interaction

دي هنرجعها أحسن من الأول.

### Closed

```text
+
```

### Tap

الـ`+` تعمل rotation حوالي 45° وتتحول بصريًا إلى:

```text
×
```

وفي نفس الوقت الـBottom Sheet تطلع.

Reverse animation.

مش Bounce مبالغ فيه.

حركة قصيرة حوالي 180–240ms.

Fluent توصي إن motion يوجه الانتباه حسب أهمية العنصر بدل استخدام animation كزخرفة. ([Fluent 2 Design System][7])

# UI-28 — Responsive Strategy

دي لازم تبقى **Adaptive**، مش responsive scaling فقط.

Apple نفسها تؤكد إن layout لازم يتكيف مع تغيير الحجم والسياق مع الحفاظ على هوية التجربة. ([Apple Developer][9]) Material 3 أيضًا يتضمن foundations للـlarge-screen/adaptive experiences. ([Material Design][10])

### Mobile

Cards / bottom navigation / full-screen forms.

### Tablet

2-column grids عند الحاجة.

### Desktop

Sidebar / constrained content / rows / desktop dialogs.

**ممنوع Mobile card يتمدد إلى 1200px.**

---

# UI-29 — Accessibility

قبل release:

* interactive targets ~44–48+
* keyboard focus واضح Desktop
* Tab order منطقي
* Escape dismiss
* semantic labels
* contrast
* text scaling
* status مش color-only
* reduced-motion support

Material foundations تشمل accessibility ضمن الأسس، وFluent/Apple كذلك يعاملوا hierarchy/adaptation كجزء من تجربة متعددة المنصات. ([Material Design][11])
